# 作業3：智慧工廠預警AI Agent開發

## 作業目的

本次作業旨在評估候選人利用 AI 工具及 AI Agents 加速工作流程、提高工作效率的能力。在任務完成過程中，自動化程度越高、所需人工干預越少、使用門檻越低，分數就越高。必須使用 AI 工具（例如：程式輔助工具、AI 搜尋引擎、AI 簡報產生工具、AI 助理、自建 AI Agent等）來完成任務並提升工作效率。

## 評分標準

* AI 工具的使用（60%）
  * 檢視在完成任務過程中對免費 AI 工具的利用程度，並需提供清楚的說明文件。
  * 利用 AI 工具實現的工作效率越高，評價越好。
* 任務完成狀況（30%）
  * 考察任務的完成情況，並確保交付成果符合各項要求。
* 技術報告品質（10%）
  * 需提交一份結構嚴謹的技術報告，闡述您的工作過程與成果。
  * 若能提供現場演示（Live Demo），將作為加分項。

## 作業描述

身為和碩（Pegatron）的機器學習應用工程師，你需要開發智慧系統以提升工廠效率。在本任務中，請建立一個模擬智慧工廠設備感測器資料的虛擬資料集，並實作一個簡單的**設備異常**預警AI Agent。目標是自動偵測模擬的異常情況，並提供即時預警。

### 虛擬資料集範例

請產生 100–500 行資料（建議使用 Python 腳本），格式如下：

```text
timestamp            temp  pressure  vibration  label
2024-06-03 19:05:00  48.2  1.01      0.03       normal
2024-06-03 19:06:00  47.9  1.01      0.03       normal
2024-06-03 19:07:00  50.3  1.06      0.06       abnormal
...                  ...   ...       ...        ...
```

### 欄位說明

| 欄位 | 定義 |
| --- | --- |
| timestamp | 記錄時間，以分鐘或五分鐘為間隔 |
| temp | 溫度；正常範圍 45–50°C，異常情況 >52 或 <43 |
| pressure | 壓力；正常範圍 1.00–1.05，異常情況 >1.08 或 <0.97 |
| vibration | 振動；正常範圍 0.02–0.04，異常情況 >0.07 |
| label | 來自感測器或 AOI 機器對設備的狀態標籤，來自感測器或 AOI 的獨立判斷 |

## 作業要求

1. 資料產生與預處理：產生上述虛擬數據，並進行基礎的資料清洗（例如：標準化、缺失值處理等）。
2. AI Agent 設計：建構一個 AI Agent，用於讀取資料、偵測異常，並在命令列中輸出結果（顯示異常情況、評分及建議）。此 AI Agent 應提供清晰且可付諸行動的資訊。
3. 示範：提供相關截圖，展示資料載入、異常偵測及警報輸出的過程。
4. AI 工具：說明你是如何利用 AI 工具來提升工作效率的，並明確列出所使用的工具（例如：ChatGPT、Copilot、AutoML 平台、程式碼產生器等）。請在報表或 README 文件中闡述這些工具在你的工作流程中扮演了怎樣的角色。
